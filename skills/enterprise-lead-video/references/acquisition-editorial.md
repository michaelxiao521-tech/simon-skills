# 获客叙事与事实边界

## 素材与传播目标匹配

每期先看素材实际包含什么，再定目标。按五项逐一记录“有 / 部分 / 无”，并附时间码或资料出处：

1. **人群与场景**：能否看出谁会用、在哪种业务场景用？
2. **产品与动作**：能否清楚展示产品、服务过程或关键操作？
3. **效果与信任**：是否有获授权的客户案例、实测结果、评价、交付记录或第三方凭据？
4. **交易信息**：是否有适用条件、采购方式、价格范围或预约流程，且企业已确认可公开？
5. **转化承接**：发布账号和实际接收线索的企业是谁；是否存在已确认、可用的咨询入口？

据此选择内容任务，而不是给素材硬套一个模板：

| 素材能证明的内容 | 更适合的任务 | 口播与 CTA 强度 |
| --- | --- | --- |
| 只有动作、外观或场景 | 认知传播、场景介绍 | 解释用途；引导了解或讨论，不暗示实际效果 |
| 有操作过程、技术资料和适用条件 | 方案介绍、意向培育 | 讲清工作方式与适用对象；可引导进一步了解 |
| 有获授权案例、可核结果和真实咨询入口 | 线索获取、预约咨询 | 用案例或结果支撑主张，给出一个明确联系动作 |
| 有价格、供给、交付条件和正式交易入口 | 促销转化 | 只在条件均已确认且当期有效时使用交易型 CTA |

“营销拓客”是总体业务目标，场景介绍和方案介绍也能服务拓客；区别在于本条视频离直接咨询有多近。缺少证据或转化承接时，降一级目标或补素材，不把软性介绍包装成高确定性的购买承诺。

例如智元 A3 Ultra 的多场景厂商视频，可见酒店、零售和汽车门店动作，适合“能力认知 / 场景介绍”。仅凭这些镜头，不能宣称已经证明稳定运营、客户收益或可采购条件；若要做预约演示型视频，需要委托方提供经确认的咨询入口、适用方案及可公开的交付或演示安排。

## 一条片只解决一个传播任务

在稿件头部写明：发布账号、委托企业、目标客户、客户所处阶段、核心主张、可用证明、单一 CTA 与转化入口。目标阶段可为“认识品牌、理解方案、比较选择、发起咨询”。阶段决定内容的力度；初次认识品牌时先让观众看懂场景，不强行索要联系方式。

可选叙事角度：

| 角度 | 开场问题 | 画面推进 | 适用输入 |
| --- | --- | --- | --- |
| 场景展示 | 这个场景现在怎样完成？ | 实际动作 → 使用步骤 → 边界 | 产品/服务实拍 |
| 痛点解决 | 哪一步最耗时或最难？ | 客户任务 → 具体做法 → 可见变化 | 真实业务过程 |
| 案例故事 | 一位客户遇到了什么？ | 真实背景 → 方案 → 经核实结果 | 已授权客户案例 |
| 产品解读 | 这项能力解决什么问题？ | 功能实拍 → 机制 MG → 适用条件 | 产品资料和演示 |
| 品牌信任 | 为什么可以考虑这家企业？ | 人员/现场/流程 → 可核凭据 | 团队、资质、交付过程 |

## 口播写法

开场先出现真实动作、问题现场或具体结果，再用一句话给观众看下去的理由。避免“震惊”“彻底取代”“行业第一”等无法证明的绝对化词。正文每段给出新信息，不连续堆卖点，也不把调查版的“究竟真假、谁在撒谎、还缺哪些实测”作为默认语气。允许说明限制，但应跟着对应主张出现。

把画面可直接看到的、企业提供的声明、第三方可核实的事实、编辑判断分别记录。厂商演示能证明“画面展示了该动作”，不能直接证明长期稳定性、客户收益、规模化部署或第三方认可。数字、评价、合作客户、认证和效果承诺必须有本期可用证据。未经客户授权，不把客户姓名、Logo 或合作关系用于宣传。

每条口播至少能回答：这句话给谁听？对应哪段画面或资料？观众听完知道什么？它是否把假设说成了事实？如答案不清楚，删减或改成可证实表达。

## CTA 与获客

结尾只留一个行动，指向真实存在且本期允许使用的入口，如“了解方案”“预约演示”“咨询适配场景”。不要把“评论、点赞、关注、私信、扫码、点击链接”同时堆在一个结尾。发布账号与委托企业不同，明确线索由谁接收；没有约定的入口时只产出带“待确认”的脚本草案，不渲染虚构联系方式。

发布前人工确认品牌关系、商业合作标识、联系方式、页面可访问性、素材授权和平台发布账号。交付包记录版本与确认状态；制作完成不自动获得发布权限。
